# 四级词库

一个按**词族**和**易混组**组织的四级单词复习网页。一个词只存一条，关系写在数据里，视图和测验自动生成。

当前词库：**2108 词**，18 个易混组，180 个词族，23 个近义组。

- 词库源文件：`words.md`（你只改这一个文件）
- 应用：`index.html` + `app.js` + `style.css`
- 进度：浏览器 `localStorage`，可导出/导入 JSON

部署后地址：

```
https://yiyinideshang.github.io/
```

手机用浏览器打开后，“添加到主屏幕”，和 App 一样。加个 service worker，地铁里没网也能背。

## 词库格式（只有三条规则）

`words.md` 按 **A–Z** 分组，每个字母有一级标题 `# A`、`# B` … 加词时放到对应字母下面。放错字母不影响网页（网页会自己按首字母分组），但 `tools/check.py` 会提醒。

```md
# C

career n. 职业；事业；生涯 /kəˈrɪr/ [族:care] [混:cancer,carrier]
- 辨析: career 长期职业道路｜job 具体一份工作｜profession 需专业训练
- 记: career 开头像 care（care + er），职业要用心经营。
- 错: 与 cancer 混；career 结尾 -reer，重音在后。

cancer n. 癌症 /ˈkænsər/ [混:career]
- 记: can + cer，中间是 n。
```

1. **一行一个词，词打头**。词性、中文、音标、标签都在这一行；空行分隔词条。
2. **关系用标签**：`[族:x]` 词根家族，`[混:a,b]` 易混组，`[近:a,b]` 近义组。**只写一边就行，程序自动双向补全。**
3. **`- ` 开头的行是补充**：`辨析` / `例` / `记` / `错` / `变形` / `近义` / `相似`，随便写，不影响解析。

以后加 `reserve`，只要写：

```md
reserve vt. 预订；保留 /rɪˈzɜːrv/ [混:preserve,observe]
```

它会自动出现在 `preserve` / `observe` 那一组里，不需要回头改旧笔记。

### 标签怎么写

| 标签 | 意思 | 例子 |
|---|---|---|
| `[族:spect]` | 同一词根/词缀家族 | `respect` `inspect` `prospect` |
| `[混:cancer,carrier]` | 长得像/读得像/容易混 | `career` `cancer` `carrier` |
| `[近:job,profession]` | 意思接近，需要辨析 | `career` `job` `profession` |

音标可以手写，也可以留空；留空时网页仍能用浏览器 TTS 朗读，只是不显示音标。

## 加词流程

1. 在 Typora 打开 `words.md`
2. 找对应字母的 `#` 标题，在下面写一行词条
3. 想加关系就写 `[混:...]` / `[族:...]`，不确定就空着
4. 保存 → 双击 `上传.bat` → 等 30 秒，网页更新

网页里的 **数据 → 格式检查** 会告诉你：有多少行没解析、引用了哪些不存在的词、缺多少词性。写完扫一眼。

第 4 周做一次合并去重：

```bash
python3 tools/check.py
```

它会列出重复词头。确认后手工合并，或把重复的两行发给我。

## 进度备份与换设备

学习进度**不会自动跨设备同步**。网站是纯静态的 GitHub Pages，没有服务器保存账号数据；进度只存在当前设备、当前浏览器的 `localStorage` 里。

### 哪些情况会同步

| 场景 | 是否同步 |
|---|---|
| 手机 ↔ 电脑 | 不会 |
| 手机 Chrome ↔ 手机 Safari | 不会 |
| 同一台手机、同一个浏览器 | 会 |
| GitHub Pages ↔ 本地 `file://` 预览 | 不会，属于不同存储位置 |
| 无痕模式 ↔ 普通模式 | 不会 |
| 清除网站数据 / 卸载浏览器后 | 会丢失 |

### 手动同步

**旧设备导出：**

1. 打开 **数据**
2. 找到 **进度备份**
3. 点 **导出 JSON**
4. 把 JSON 发到微信 / 网盘 / 邮箱

**新设备导入：**

1. 打开同一个网站
2. 进 **数据**
3. 点 **导入**
4. 选刚才的 JSON
5. 确认覆盖当前进度

注意：

- 导入是**覆盖**，不是合并。两边都有进度时，当前设备的进度会被替换。
- 导出的 JSON **只包含学习进度**，不包含单词本身；词库仍然从网站上加载。
- 导出只是一次快照。之后继续复习，新进度不会自动写进旧文件，要重新导出。
- 换手机、清缓存、卸载浏览器前，先导出一次。

### 建议

- 固定用**手机当主力复习设备**
- 电脑只用来看词、加词
- 每隔几天在手机上 **导出一次 JSON** 备份
- 换手机前一定先导出
- 如果在意进度，不要随便清除网站数据

> 想要“手机和电脑自动同步”，需要额外的后端账号系统（如 Supabase / Firebase）把进度存云端。当前版本没有这个功能。

```
├── 迁移报告.md              迁移时的检查报告（不进仓库）

    ├── migrate.py          原始 md → 词库
    ├── postprocess.py      清洗、修错、合并
    ├── letter_headings.py  给 words.md 加 A–Z 标题
    ├── merge_families.py   合并被拆开的词族
    ├── enrich.py           补音标/词性（词典 API）

```

> `migrate.py` / `postprocess.py` 只用于最初的迁移。以后加词直接改 `words.md`，不要重跑这两个，否则会覆盖你手工加的词。`letter_headings.py` 可以随时重跑，只整理标题。

`sources/`、`迁移报告.md`、`build/` 在 `.gitignore` 里，不会公开。`words.md` 会公开（GitHub Pages 要读它），别往里写私人内容。

## 出题逻辑

复习页先选题型：

- **混合复习**：按“复习 → 设置 → 每天复习”的词数取词（默认 30，属于每日上限）：先取今日到期词，不够再补未学新词；按 看单词选中文 → 看中文选单词 → 听音选词 → 拼写 各过一遍；拼写跳过短语，拼错排到队尾重拼。本轮按单词答错次数定盒：0 错盒 5、1 错盒 4、2 错盒 3、3 错盒 2、4 错及以上盒 1。
- **听音选词**：浏览器 TTS 朗读，4 选 1
- **拼写**：中文 + 音标 + 首字母提示，键盘输入；自动跳过短语
- **看中文选单词**：4 个英文单词
- **看单词选中文**：4 个中文释义

干扰项优先从同一易混组/词族/形近词里抽。单题模式共用同一套盒子进度（1/2/4/7/14 天）；答错回盒子 1。混合复习最终按本轮错次定盒。选中选项后会自动朗读正确单词，拼写检查后也会朗读。每天复习词数是每日上限：完成后当天不再出题，未复习的到期词留到明天。

## 4 周节奏

| 时间 | 做什么 |
|---|---|
| 第 1 天 | 迁移、去重、补音标、上线 |
| 第 2–3 天 | 每天 30 个词，混合/听音/拼写轮换；不熟的词在详情页标“不认识” |
| 第 4 天起 | 每天清到期 + 易混擂台 2 组；不再加功能 |
| 每周末 | 一套真题，生词入库 |
| 第 4 周 | `tools/check.py` 合并去重一次 |

**第 3 天之后不要再改应用。** 工具只用来省时间，不要让它吃掉复习时间。
